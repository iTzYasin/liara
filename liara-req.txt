مستندات لیارا
برای آشنایی با سرویس‌ها، قابلیت‌ها و مستندات فنی لیارا می‌توانید از منابع زیر استفاده کنید:

مستندات رسمی لیارا:

https://docs.liara.ir/

مخزن GitHub مستندات لیارا:

https://github.com/liara-cloud/docs

خروجی نهایی
خروجی نهایی پروژه باید شامل موارد زیر باشد:

لینک نسخه Deploy شده پروژه روی زیرساخت لیارا
لینک GitHub پروژه
پروژه باید به‌صورت کامل روی زیرساخت لیارا قابل اجرا و استفاده باشد.

در صورت عدم امکان Deployment
اگر تیمی به هر دلیل موفق به Deploy پروژه روی لیارا نشد، می‌تواند برای ارزیابی سایر بخش‌های پروژه، یک ویدئوی دمو از محصول ارسال کند.

ویدئوی دمو باید قابلیت‌های پیاده‌سازی‌شده را به‌صورت کامل نمایش دهد.

توجه: در این حالت، امتیاز مربوط به بخش استقرار روی زیرساخت لیارا به تیم تعلق نخواهد گرفت، اما سایر بخش‌های پروژه همچنان قابل ارزیابی خواهند بود.
